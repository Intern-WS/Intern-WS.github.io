# Disability Lawyer Illinois

This project was generated with `npm create accessible-astro-starter@latest`.

## Included setup

- Preset: Minimal
- Launcher: Removed

## Getting started

```bash
npm install
npm run dev
```

## What to customize first

- Update `theme.config.ts` with your site name, metadata, and navigation.
- Replace the placeholder copy in `src/pages/`.
- Adjust colors and spacing tokens in the theme and SCSS as needed.

## Available commands

| Command | Action |
| :------ | :----- |
| `npm run dev` | Start the local dev server |
| `npm run build` | Build the production site |
| `npm run preview` | Preview the production build locally |

## Design

The full site uses the selected guided visual system: soft blue backgrounds,
rounded bordered panels, numbered steps, deep navy actions, and restrained gold
accents. Section-level comments in the Astro and SCSS files explain the page
structure and styling decisions.

The earlier comparison routes have been removed. The guided homepage is now the
public, indexable page at `/`.
